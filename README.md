Как открыть и собрать конфигурацию

- Откройте базу в Конфигураторе.
- В меню: «Администрирование» → «Загрузить конфигурацию из файлов».
- Укажите корневую папку репозитория (где находится `Configuration.xml`).
- Подтвердите загрузку — платформа соберёт конфигурацию из файлов.
- После загрузки выполните «Обновить конфигурацию базы данных» (F7).
- Запустите в режиме «1С:Предприятие» для проверки объектов.
